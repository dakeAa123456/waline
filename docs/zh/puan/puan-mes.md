:::tip 打印标签模板

打印标签模板使用的是润乾报表软件，在此软件上绘制我们需要的产品包装模板（原材料、半成品、成品）和库位模板（托盘模式、货架模式）下面将详细介绍一下在服务端和客户端如何正确生成打印模板。
:::

## **_准备工作_**

---

1. 首先在[润乾官网](https://www.raqsoft.com.cn/download/download-jsbb)下载安装[润乾软件安装包](https://code.puancn.top:3001/uploads/docs/润乾软件/report-install-20260914.zip)到服务器端，安装路径一般是`D:\raqsoft`，目前最新的安装包是`20260914`，记录日期是：2026-10-16.

2. 然后在服务器端登录[MES系统](http://mes.puankj.top:10050/gdpaas/home/index.htm)后台，找到打印模板设置，具体路径如下：后台管理页面 -> 账号头像 -> 运维管理 -> 润乾打印模板设置

![本地目录](/puan/muban.png)


3. 最后开始在服务器端的润乾软件上制作标签打印模板，制作完成后保存到本地服务器，再选中打印文件上传到MES系统当中去，前端即可接收到打印模板。


## **_库位模板_**

### 服务端

1. 选择服务器上已有的货架打印模板，双击使用润乾报表打开，可以自由调整打印模板数据内容，例如：我要打印的标签纸是90*50mm，可以这样设计，如下图所示：

![本地目录](/puan/9050.png)

2. 90*50mm打印模板设计完成后，先保存在本地盘符当中，然后登录MES系统后台，选择`报表打印模板设置`,完成打印模板上传即可，稍后可以在前端新建打印模板进行测试验证，至此，服务器端已完成初步工作。

![本地目录](/puan/dayin1.png)

### 客户端

3. 运维管理人员登录[MES系统](http://mes.puankj.top:10050/gdpaas/home/index.htm)，对刚刚在服务器端新建上传的90*50打印模板进行配置，具体路径如下：SYS -> 系统管理 -> 业务对象 -> 单据类型
进入`单据类型`模块后，根据`名称`搜索`库位`，就可以找到对应的库位单据，如下图所示：

![本地目录](/puan/dayin2.png)

4. 在`单据类型`模块，选中`库位`列表项，点击按钮`打印格式`，进入新的功能模块页面，再新增打印模板，根据弹窗选择填写如下内容，例如：

- 格式名称：库位-货架码

- 打印模板类型：内置

- 打印模板ID：PP-25B0-A742-94FC4A84

- 打印模板：此处是下拉列表选项，选择之前在服务器端上传的模板

- 保存即可

![本地目录](/puan/dayin3.png)



## **_产品包装模板_**

### 服务端

1. 产品包装模板与库位模板在服务端的使用方式是一样的，都需要使用润乾报表软件进行自主设计，设计完成后保存在本地，然后登录mes系统后台进行上传，此处不再展开赘述。

2. 产品包装打印模板如图所示：

![本地目录](/puan/dayin4.png)

### 客户端

3. 运维管理人员登录[MES系统](http://mes.puankj.top:10050/gdpaas/home/index.htm)，对刚刚在服务器端新建上传的90*70原材料打印模板进行配置，具体路径如下：SYS -> 系统管理 -> 业务对象 -> 单据类型
进入`单据类型`模块后，根据`名称`搜索`条码`，就可以找到对应的条码生成单据，如下图所示：

![本地目录](/puan/dayin5.png)

4. 在`单据类型`模块，选中`条码生成`列表项，点击按钮`打印格式`，进入新的功能模块页面，再新增打印模板，根据弹窗选择填写如下内容，例如：

- 格式名称：原材料-包装码

- 打印模板类型：内置

- 打印模板ID：PP-9BE5-E324-B40B4393

- 打印模板：此处是下拉列表选项，选择之前在服务器端上传的模板

- 保存即可

![本地目录](/puan/dayin6.png)

## **_结语_**

5. 在此功能模块`打印格式`可以自由新增、修改打印模板，前提是服务器端要上传新的模板，这边才能正常操作，否则获取不到相关数据。
