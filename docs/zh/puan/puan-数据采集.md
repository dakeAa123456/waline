## **_总览介绍_**

当SGIP工单创建完成后，还有一系列的子模块数据需要新增上传到国网平台的，这部分数据主要是记录配电箱产品从原材料到成品入库的全过程,其中有两个子模块数据采用的是设备自动采集，并不是手工新增，如下图所示：


自动设备采集数据子模块

- 配电箱 / 工频耐受试验

- 配电箱 / 保护措施和保护电路的连续性验证

![本地目录](/puan/sgip022.png)


## **_工频耐受试验_**

1. 点击子模块`配电箱 / 工频耐受试验`,进入编辑页面，连接实验设备，根据如下表单属性填写正确的值：

| 序号 |   属性              |    示例值      |     释义
| :--: | :--------:         | :--------:     |   :--------:     |
|  1   |   工单号          |   MO20261024001  |                  |
|   2   |  产品编号         | 102.03.2900001 |                  |
|   3   |  实验设备编号         | ECNY01          |                  | 
|  4    |  Ecode        |  NotImp          |                  |
|  5    |  SGIP实物ID        |  NotImp         |                  |
|  6    |  试验项目        |  极与辅助回路          |                  |
|  7    |  试验电压 (V)        |  220          |                  |
|  8    |  试验持续时间 (s)     |  180          |                  |

![本地目录](/puan/sgip023.png)

2. 连接设备，开始试验，数据采集成功，确认无误后，点击`上传`按钮即可。


## **_保护措施和保护电路的连续性验证_**

3. 点击子模块`护措施和保护电路的连续性验证`,进入编辑页面，连接实验设备，根据如下表单属性填写正确的值：

| 序号 |   属性              |    示例值      |     释义
| :--: | :--------:         | :--------:     |   :--------:     |
|  1   |   工单号 *          |   MO20261024001  |                  |
|   2   |  产品编号 *         | 102.03.2900001 |                  |
|   3   |  生产设备唯一识别号 *         | JDDZ01          |                  | 
|  4    |  测量电流（A）        |   **         |    设备获取               |
|  5    |  测量电阻 (mΩ)       |    **       |      设备获取            |

![本地目录](/puan/sgip024.png)

4. 连接设备，开始试验，获取实验结果，数据采集成功，确认无误后，点击`上传`按钮即可。
