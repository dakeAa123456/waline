## **_配电箱25-文件上传_**

7. 与原材料相关的配电箱01 - 配电箱09的工序都需要上传`来料检测报告`和`生产商检测报告`，在底部菜单`文件管理`中上传完成后，需要在`配电箱25-文件上传`这道工序里完成对应链接的新增，新增内容如下表所示：

| 序号 |   属性              |    示例值                 |     释义                 |
| :--: | :--------:         | :--------:               |   :--------:            |
|  1   |   供应商工单编号*    |  WO20261021001          |                        |
|   2   |  唯一标识        |   WO20261021001            |                         |         
|   3   |  文件数组*        | http://192.168.110.200/talula/proxy/oss/eip-files/LLJYBG.pdf/1    |  1代表来料检测报告 / 2代表生产商检测报告                      | 
|   4    | 附件所属工序*      |  GX000071                   |  在原材料工序当中查找                        |
|   5    | 感知过程*                 |  1              |                        |

编辑页面如下图所示：

![本地目录](/puan/sgip033.png)

- 文件数组字段需要填写的链接在底部菜单`文件管理`中寻找，本地上传完成后，一般都会有两个链接，分别是`来料检测报告`和`生产商检测报告`，检测报告的链接需要根据所属的原材料进行对应，切勿随意填写，否则会出现A原材料上传了B的检测报告等错误。

- 附件所属工序字段需要填写的是`pdCode`属性后面的值，具体路径是：底部菜单物联数据 -> 01 - 09 原材料工序 -> 选择检测报告对应的原材料，点击进入数据列表 -> 点击右上角图标，如图所示：

![本地目录](/puan/sgip032.png)

8. 编辑完成后保存，在数据表格列表页就可以看到刚刚新建的一条新记录，列表数据二次确认无误后，选中列表项，点击`准备就绪`，记录上传到国网平台。
